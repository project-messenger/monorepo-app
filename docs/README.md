## Где что писать

- Касается нескольких частей монорепы (git, контракт API, авторизация, инфраструктура) → `docs/` в корне.
- Касается только одной части (FSD, модули Nest) → `apps/<app>/docs/` или README пакета.
- Решение «почему так», которое переживёт одну задачу → ADR в `docs/adr/`.
- Правило, которое должен соблюдать агент → `AGENTS.md` нужного уровня (подробности — в [ИИ-агенты](./ai-agents.md#как-менять-правила)).

Confluence — для командных договорённостей и обсуждений. То, что нужно агентам и коду, должно жить здесь: агенты
Confluence не читают.
