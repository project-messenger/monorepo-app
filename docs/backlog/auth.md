# Авторизация

[← к бэклогу](./README.md) · Jira: —

## Зачем

Способ входа не выбран. Код в `apps/web/src/features/auth` (кнопки Google/GitHub) — заготовка из шаблона, а в макете
вход по логину и паролю. Пока это не решено, бэкенд под заготовку не строим
(см. [docs/architecture.md](../architecture.md#авторизация)).

## Что важно из ТЗ

- Права проверяются не только в HTTP, но и в событиях WebSocket, поиске, скачивании файлов и запросах к ИИ.
- Удалённый из закрытого канала участник не должен получать новые сообщения через уже открытое соединение.
- Токены **интеграций** (GitHub) не попадают во фронтенд и в логи. Про способ входа пользователя ТЗ ничего не требует.
