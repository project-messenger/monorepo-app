# 04. Размеры, радиусы, границы, отступы

[← к индексу](./README.md) · Статус: ✅ готова (радиусы; остальное решено без новых токенов) · Зависит от: 01

## Зачем

Привести шкалу радиусов, толщину границ и размеры контролов к значениям макета, чтобы компоненты брали их из токенов, а не из «магических» чисел.

## Данные макета

- Радиусы: 4, 5, 6, 7, 8, 9, 10, 12, 14, 24 px.
- Границы: 1 и 1.5 px.
- Высоты контролов: 34, 36, 40, 44, 45, 48, 50, 52, 72, 86 px.
- Отступы: см. `figma-data.md`.

## Решения

- Шкала радиусов в `@theme inline` (`apps/web/src/_app/styles/globals.css`) задана абсолютными значениями макета:

| Утилита | Значение | Где в макете |
| --- | --- | --- |
| `rounded-sm` | 6 px | Search, Input `settings`, Alert `destructive` |
| `rounded-md` | 7 px | Button `app`, Input/Textarea/Select `app`, Alert `warning`, StatusSelect |
| `rounded-lg` | 8 px | Button `auth`/`landing`, TaskCard, WorkspaceSwitcher, Alert `success` |
| `rounded-metric` | 9 px | MetricCard |
| `rounded-xl` | 10 px | Card `feature`, Input `auth` |
| `rounded-2xl` | 12 px | зарезервировано шкалой макета |
| `rounded-3xl` | 14 px | зарезервировано шкалой макета |
| `rounded-4xl` | 24 px | зарезервировано шкалой макета |

- `--radius` оставлен `0.5rem` (8 px): им пользуются `sonner` и `calc(var(--radius) - …)` в `input-group`.
- Радиусы 4 и 5 px отдельными токенами не заводим: в компонентах макета они не встречаются.
- Высоты контролов отдельными токенами не заводим: варианты `size` в `cva` выражаются утилитами `h-10`, `h-11`, `h-12`. Нестандартные 45, 50, 52 берутся произвольными значениями только в конкретных компонентах при подгонке (подзадачи 05–08).
- Границы: 1 px дефолт Tailwind, 1.5 px только у TaskCard `review` (highlighted), токен не нужен, применяется в подзадаче 08.
- `--spacing` остаётся 4 px (Tailwind v4). Нестандартные значения (6, 7, 9, 11, 13, 17, 21, 29, 51) в токены не выносим, пока не встретятся в `shared/ui`.

## Чеклист

- [x] Решено: отдельные токены высот контролов не нужны, используются варианты `size` в `cva`.
- [x] Граница 1 px дефолт, 1.5 px отдельным токеном не заводится (одно использование в TaskCard).
- [x] `--spacing` проверен: нестандартные значения в токены не выносятся.
- [ ] Размер иконок по умолчанию (`size-4`) сверить с макетом при подгонке компонентов (подзадачи 05–08).
- [x] Проверено через временный файл со всеми классами и `pnpm --filter web build`: утилиты `rounded-*` генерируются с нужными значениями. Файл-проба удалён.
- [x] `pnpm --filter web verify` зелёный (typecheck, ESLint + steiger, Prettier, 65 тестов).

## Готово, когда

Радиусы и размеры компонентов `shared/ui` берутся из токенов и совпадают с макетом.

## Не проверено

- Внешний вид компонентов в браузере: радиусы `rounded-md` (7 px) и `rounded-lg` (8 px) изменили вид существующих компонентов `shared/ui`, они ещё не подгонялись под макет (подзадачи 05–08).
