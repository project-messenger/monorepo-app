# Процесс релиза

[← к бэклогу](./README.md) · Jira: —

## Зачем

ТЗ: «Релизы через отведение ветки + нажатие кнопки release в github», «релиз в прод должен быть лёгким и удобным,
одним нажатием кнопки». Также обязательны контейнеризация при деплое, логи и метрики в проде. Сейчас ничего из этого
не настроено (см. [ADR-0003](../adr/0003-trunk-based-development.md)).

## Решения до начала

- [ ] Схема: от `main` отводится ветка `release/<версия>`, по кнопке (GitHub Release или ручной запуск workflow)
      собираются образы и выкатываются. Нужна ли защита веток `release/*` в ruleset.
- [ ] Куда деплоим — зависит от организаторов курса.

## Что сделать

- [ ] Dockerfile для `web` и `api` (продолжение [Docker](./docker.md)).
- [ ] Workflow релиза в `.github/workflows/`, секреты — в GitHub Secrets.
- [ ] Описать процесс в `docs/workflow.md`.
