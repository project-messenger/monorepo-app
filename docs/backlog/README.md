# Бэклог технических задач

[← к документации](../README.md)

Черновики задач, которые уже понятны, но ещё не взяты в работу: что сделать, зачем (обычно — требование ТЗ) и какие
решения нужны до начала. Это не замена Jira: здесь только технические задачи по устройству репозитория, которые
всплыли по ходу других задач и которые удобно читать рядом с кодом — в том числе ИИ-агенту.

## Как пользоваться

1. Берёте задачу — заводите её в Jira (`KAN-*`) и ставите ссылку на ключ в файле.
2. В PR, который задачу закрывает, **удаляете файл** и строку из таблицы. Если сделали частично — оставляете в файле
   только то, что осталось.
3. Появилась новая техническая задача «на потом» — добавьте файл по образцу соседних и строку в таблицу.

ИИ-агент может читать эти файлы для контекста, но **не берёт задачу отсюда сам** — только если пользователь попросил.
