# 0013. Общий dev-стенд: отдельный Compose и Nginx

- **Статус:** предложено; структура и Nginx согласованы пользователем, ожидает ревью PR
- **Дата:** 2026-11-27
- **Область:** весь проект
- **Подготовил:** ИИ-агент (Codex) по запросу пользователя
- **Задача:** [KAN-47](https://project-group-11.atlassian.net/browse/KAN-47), часть KAN-46

## Контекст

Нужен общий dev-стенд API, PostgreSQL и Redis, позднее — автоматическое обновление из проверенного main
и мониторинг (KAN-46). Локальный Compose из ADR-0010 обслуживает другой сценарий: приложения работают
на компьютере разработчика. Production будет отдельным окружением, процесс релиза ещё не реализован.

## Варианты

1. Расширить локальный Compose окружениями и overrides: меньше повторений, но настройки локального
   запуска и удалённого стенда становятся связаны.
2. Отдельный Compose в `deploy/dev/`: явный состав стенда и независимые данные, небольшое повторение
   конфигурации PostgreSQL/Redis.
3. Reverse proxy Caddy с автоматическим HTTPS или Nginx с отдельно организованным выпуском сертификатов.
   Codex предложил Caddy; пользователь выбрал Nginx.

## Решение

Пользователь согласовал `deploy/dev/` и Nginx. В `apps/api/Dockerfile` — общий образ API для стенда
и будущего production. Образ собирается из корня монорепозитория, включает production-зависимости
и собранный `@app/shared`, работает непривилегированным пользователем.

Compose принимает готовый образ API; окружение передаётся при запуске. База и Redis находятся
во внутренней сети без опубликованных портов. Данные сохраняются в именованных volumes.
Nginx принимает HTTP/HTTPS и проксирует API и будущий Socket.IO. Сертификаты и секреты находятся вне Git.
Выпуск и автоматическое продление сертификатов с reload Nginx настраиваются в KAN-48.

## Последствия

Локальные команды остаются прежними. KAN-49 доставляет образ и конфигурацию из одного проверенного коммита;
KAN-50 расширяет этот стек мониторингом. Production позднее получит `deploy/prod/`, свой frontend,
секреты, сети и данные. Общий Compose пока не выделяем: второго реализованного окружения нет.
Инструкция и ограничения проверок — [deploy/README.md](../../deploy/README.md).
