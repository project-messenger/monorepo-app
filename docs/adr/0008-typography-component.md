# 0008. Компонент Typography для текста

- **Статус:** принято
- **Дата:** 2026-11-16
- **Область:** web
- **Подготовил:** ИИ-агент по запросу команды
- **Задача:** —

## Контекст

По [ADR-0007](./0007-figma-uikit-implementation.md) роли макета (`--text-<роль>`) применяются классами Tailwind
(`text-body`, `text-heading-page`), а компонент `Typography` не создаётся. На практике теги `h1`–`h6`, `p`, `span`
не имеют базовых стилей: preflight Tailwind сбрасывает размер и вес заголовков, и без класса текст выглядит как
обычный. Каждый раз вручную подбирать класс роли и не забыть его — источник ошибок. Кроме того, в макете нет ролей
для `h5` и `h6`.

## Варианты

1. **Только классы** — писать `className="text-heading-page"` на каждом теге. Плюсы: ничего нового, нет обёртки.
   Минусы: легко забыть класс, роль не связана с тегом.
2. **Компонент `Typography` с пропом `as`** — один компонент рисует любой тег, роль выбирается по умолчанию для
   тега, её можно переопределить пропом `variant`. Плюсы: тег и роль согласованы, код короче. Минусы: ещё одна
   обёртка, которую нужно поддерживать.

## Решение

Выбран вариант 2: `apps/web/src/shared/ui/typography.tsx`.

- Пропсы: `as` — тег (`h1`–`h6`, `p`, `span`, `div`, `label`), `variant` — роль. Остальные HTML-атрибуты
  передаются в тег.
- Роль по умолчанию берётся из тега: `h1` — `heading-page`, `h2` — `heading-section`, `h3` — `heading-panel`,
  `h4` — `heading-subsection`, `p`/`span`/`div` — `body`, `label` — `label-field`.
- Для `h5` и `h6` роли в макете нет. Выбраны близкие по размеру роли: `h5` — `label-button` (15 px),
  `h6` — `label-field` (13 px). Это заменитель, а не решение дизайна: при появлении роли в макете заменить.
- Класс роли задаётся через `cva` и объединяется с `className` через `cn`, поэтому переопределение работает.

Это уточняет [ADR-0007](./0007-figma-uikit-implementation.md) в части «Компонент `Typography` не создавался».
Классы ролей остаются основным способом: компонент нужен там, где тег и роль должны совпадать.

## Последствия

- В `AGENTS.md` и `apps/web/docs/stack.md` добавлено упоминание компонента; запрет на `Typography` снят.
- Новые роли добавляются в `globals.css` и в `typography.tsx` (тип `variant` и `defaultVariantByTag`).
- Компонент пока без тестов и стори: их нужно добавить по правилам фронтенда (`AGENTS.md`, «Done»).
- Заменители для `h5`/`h6` надо согласовать с макетом Figma.
