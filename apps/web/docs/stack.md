# Стек: какая библиотека для чего

[← к README](../README.md)

Для каждой зависимости: **что это**, **зачем она нам**, **где лежит** и **как правильно использовать**.

Статусы:

- **Работает** — подключено и используется в коде.
- **Готово к использованию** — пакет установлен и настроен, но фич на нём ещё нет: используйте его, когда
  дойдёте до соответствующей задачи, а не ищите альтернативу.

> Новую зависимость добавляем только после обсуждения в команде: сначала проверьте, нет ли в этом списке
> библиотеки, которая уже решает задачу.

## 1. Каркас

| Библиотека                          | Что это и зачем                                                                                                                                                                                                    | Статус   |

| **Turborepo** (корень)              | Запускает задачи во всех пакетах монорепы и кэширует их                                                                                                                                                            | Работает |

**Правила UI** (подробно — в [AGENTS.md](../AGENTS.md)):

- Новый компонент — сначала `pnpm --filter web exec shadcn add <компонент>`, а не писать с нуля.
  CLI спросит про перезапись существующих файлов — отвечайте «нет», если не обновляете компонент намеренно.
- Только токены темы: `bg-primary`, `text-muted-foreground`. Никаких `bg-[#0f172a]`.
- Не меняйте логику и доступность в `shared/ui` — только стили и варианты.

## 4. Формы

| Библиотека              | Что это и зачем                                                   | Где                                     | Статус   |
| ----------------------- | ----------------------------------------------------------------- | --------------------------------------- | -------- |
| **react-hook-form**     | Состояние формы без лишних ререндеров: значения, ошибки, отправка | `features/auth/ui/*-form.tsx` — образец | Работает |
| **@hookform/resolvers** | Мост: отдаёт валидацию формы zod-схеме (`zodResolver(schema)`)    | там же                                  | Работает |

Как устроена форма (образец — `features/auth`):

1. Схема в `model/schemas.ts`: правила полей и тексты ошибок на русском.
2. В компоненте `useForm({ resolver: zodResolver(schema), defaultValues })`.
3. Обычные инпуты — `{...register("email")}`; компоненты Base UI (чекбокс, селект) — через `<Controller>`.
4. Ошибки — `<FieldError errors={[errors.email]} />` из `shared/ui/field`.

## 5. Чат

| Библиотека                                                 | Что это и зачем                                                                                                                                                                                                                                                                         | Статус                 |

| `@tiptap/extension-mention` + `@tiptap/suggestion`         | Упоминания `@пользователь` и ссылки на задачи с выпадающим списком подсказок                                                                                                                                                                                                            | Готово к использованию |

| **react-markdown** + **remark-gfm**                        | Показ сообщений и ответов ИИ из markdown. `remark-gfm` добавляет таблицы, зачёркивание, списки задач                                                                                                                                                                                    | Готово к использованию |
| **rehype-sanitize**                                        | Вычищает опасный HTML из markdown (защита от XSS). **Всегда** подключайте вместе с `react-markdown` для пользовательского текста                                                                                                                                                        | Готово к использованию |
| **shiki**                                                  | Подсветка синтаксиса в блоках кода (та же, что в VS Code). Тяжёлая — грузите лениво                                                                                                                                                                                                     | Готово к использованию |

> Формат хранения текста сообщений (markdown или JSON Tiptap) ещё **нужно согласовать с бэкендом**.
> Рекомендация — markdown: его проще искать и отдавать ИИ.
